Executive Summary

The Online Test Platform represents a comprehensive educational technology solution designed to facilitate secure, monitored online examinations. Built on modern web technologies, the platform provides a complete ecosystem for educational institutions to conduct fair, transparent, and technically robust online assessments.

This documentation provides detailed specifications for all system components, user interfaces, and operational procedures. The platform serves three distinct user categories through specialized portals, ensuring role-appropriate functionality and security measures.

1. System Overview

Platform Architecture

The Online Test Platform employs a multi-tier architecture consisting of three specialized frontend portals and a centralized backend infrastructure. This design ensures optimal separation of concerns, enhanced security, and scalable performance.

1.1 Core Components

Component Technology Stack Primary Function
Student Portal React.js, Vite, Tailwind CSS Test-taking interface with proctoring
Administrative Portal React.js, Vite, shadcn/ui System administration and management
Evaluator Portal React.js, Vite, Radix UI Internal assessment and evaluation
Backend Server Node.js, Express.js, MongoDB API services and data management

1.2 Technology Infrastructure

Backend Technologies

  • Node.js (v18+) - Server-side JavaScript runtime environment
  • Express.js (v4.18.2) - Web application framework providing RESTful API architecture
  • MongoDB with Mongoose ODM (v8.18.1) - NoSQL database with object modeling
  • JWT Authentication (v9.0.2) - Token-based security implementation
  • Puppeteer (v24.22.3) - PDF generation and report processing

Frontend Technologies

  • React.js (v18+) - Component-based user interface library
  • Vite - Modern build tool and development server
  • Tailwind CSS (v4.1.12) - Utility-first CSS framework
  • Radix UI Components - Accessible component primitives

3. Student Portal Specifications

The Student Portal provides a secure, monitored environment for online test administration with comprehensive proctoring capabilities and user-friendly interface design.

3.1 Test Interface Architecture

3.1.1 Question Randomization Protocol

Algorithm Specification: The system implements a multi-layered randomization approach ensuring unique test experiences while maintaining assessment validity.
Randomization Level Implementation Purpose
Question Selection Random sampling from question pool Unique question sets per student
Question Sequence Shuffling of selected questions Prevents collaboration based on order
Option Arrangement Random ordering of answer choices Eliminates pattern-based cheating
Pool Distribution 70-question allocation from larger pools Ensures comprehensive coverage

3.1.2 User Interface Layout Specifications

Split-Screen Interface Design

The test interface employs a dual-panel layout optimized for efficient navigation and clear visual organization of test components.

Panel Content Functionality
Left Panel (70% width) Current question and answer options Primary interaction area for question answering
Right Panel (30% width) Question navigation grid and status indicators Question jumping and progress tracking
Status Color Coding System:
  • ■ Green: Question answered (response recorded)
  • ■ Orange: Marked for review, unanswered
  • ■ Purple: Marked for review and answered
  • ■ Gray: Not visited or attempted

3.2 Data Persistence and Recovery Systems

3.2.1 Multi-Layer Save Architecture

  1. Automatic Save Protocol
    Continuous background synchronization with server database at configurable intervals (default: 15 seconds) ensuring minimal data loss risk.
  2. Manual Save Functionality
    User-initiated save operations providing immediate confirmation and peace of mind for critical response preservation.
  3. Local Storage Backup
    Browser-based local storage implementation maintaining response cache for offline recovery and connection failure scenarios.
  4. Recovery Mechanism
    Automatic restoration of locally cached responses upon reconnection, with conflict resolution protocols for data synchronization.

3.3 Security and Monitoring Framework

3.3.1 Proctoring System Specifications

Security Component Implementation Method Violation Response

Copy-Paste Prevention Event listener disabling and keyboard hook interception Action blocking with violation logging

Security Protocol: All monitoring activities are conducted in compliance with institutional privacy policies and applicable regulations. Students are informed of monitoring scope and data handling procedures prior to test commencement.
